Road Accident Analysis Dashboard | Power BI

Project Overview
This project uses Microsoft Power BI to analyze road accident data and identify patterns in casualties, accident severity, vehicle categories, road types, environmental conditions, and geographical locations.

The dashboard combines key performance indicators (KPIs), trend analysis, comparative visuals, and geographical mapping to support data-driven insights into road safety.

Objectives
- Analyze total casualties and accident counts.
- Compare current-year and previous-year casualty trends.
- Examine casualties by accident severity and vehicle type.
- Identify patterns across road types, lighting conditions, and urban/rural areas.
- Explore geographical variations in casualties.
- Enable interactive analysis using weather and road surface condition filters.

Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Visualization
- KPI Reporting
- Time-Series Analysis

Key Features
- Current-year and year-over-year KPI cards
- Monthly casualty trend analysis
- Casualties by vehicle type and road type
- Urban versus rural casualty distribution
- Analysis by lighting conditions
- Geographical casualty mapping
- Interactive weather and road surface filters

Business Value
The dashboard helps stakeholders explore road accident patterns, compare performance over time, and identify areas that may require further investigation for road safety planning.
